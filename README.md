# Pokémon: Efteling League

Startmenu prototype (versie 0.1).

## Starten
Open `index.html` in een moderne browser.

## Bestanden
- `index.html` — structuur van het startmenu
- `style.css` — vormgeving en responsive layout
- `script.js` — menu-interactie en toetsenbordbediening
- `assets/title-screen.svg` — zelfgemaakte pixel-art achtergrond

## Bediening
- Pijltje omhoog/omlaag: menuoptie kiezen
- Enter of muisklik: bevestigen
- Escape: dialoogvenster sluiten

New Game en Options tonen momenteel tijdelijke meldingen. Save-systeem, trainercreatie en starterselectie volgen in latere ontwikkelstappen.
